# Palette auditions and Shuffle

- Well clicks call `auditionInstrument`, which reuses the instrument picker's `resumeAudioContextIfNeeded` / `triggerInstrument` engine and the shared `isPitchedEvent` classifier. A dedicated preview bus at 50% gain feeds the normal master bus and its volume/mute. It has no board object or recording owner, and runs outside playback-occurrence context.
- Pitched previews use middle-register C4 through the normal musical-pitch resolver. Percussion uses the engine's unpitched sample path (`pitched:false`, `pitchShift:false`). Previews preserve each instrument's native envelope and sample tail, matching the picker; no custom strum envelope truncates the sound or replaces synth timbre. A new tap cancels the previous preview voice.
- Only click auditions: pointerdown starts the hold timer. Confirmed long-press, pointer cancellation and movement beyond the tap threshold suppress the following click. Second-tap unequip still auditions once. Empty wells open configuration silently.
- Shuffle reads `getInstrumentEntries` / `loadInstrumentEntries`, the same catalogue as configuration, filtered by the current `getSoundThemeKey`. Fisher–Yates shuffles unique canonical IDs; six are selected without replacement when possible. Smaller pools repeat. Useful swaps avoid retaining an instrument in the same slot where possible. An unavailable/empty theme does not replace assignments.
- Shuffle immediately clears Instrument, Randomise or Eyedropper, then replaces and persists wells using the existing `rhythmake:paint-slots` key. No preview sequence is played. Shared colour overrides and board toys are untouched. The control is separate from Randomise and uses a brief animation, or brightness fade with reduced motion.
- Unit tests cover preview routing/classification, isolation, theme filtering, distinct selection, small pools, tool clearing, shared colours and persistence. Browser tests tap all six wells and second-tap unequip, confirm long-press/drag suppression, measure actual Web Audio output, compare authored board/transport snapshots, verify silent Shuffle and reload, and inspect the 390px layout.
- Browser audio reached the preview analyser with the context running. This verifies generated audio and routing; no subjective listening assessment was performed. Screenshot: `artifacts/palette-shuffle-narrow.png`.
