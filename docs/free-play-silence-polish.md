# Free Play silence polish

This supersedes the coverage, Wash and static-droop descriptions in `free-play-silence-mechanics.md`. The authored state remains `scissorMuted || paintCovered`; source MIDI, event timing, duration and original geometry are unchanged.

1. **Previous disagreement.** Coverage was sampled once in CSS pixels when a splat landed, then retained as cached note IDs. Canvas resizing and Uncoil could change the apparent overlap. Rendering also added black footprints absent from that original test. Finally, a splat stored on one line could visibly cover another line without contributing to its mute state.
2. **Canonical coverage.** `paintShapes()` defines thirteen seeded ellipses in one fixed logical surface space. `paintShapeContains()` tests the musical node center against those exact ellipses, including the boundary. `drawPaintShapes()` renders the same shapes; it adds no black shadows or footprints outside them. `evaluateScenePaint()` considers every line against every visible splat, replacing cached coverage IDs. CSS dimensions only project this shared space. Normal DrawGrid has disabled/source-note masks, but no pre-existing black-splat geometric coverage rule to reuse. The existing canonical authored-note playback gate is retained.
3. **Re-evaluation and removal.** Paint edits commit coverage immediately. Stable node IDs/positions, paint or coiled/uncoiled layout changes invalidate the coverage signature. The main audio scheduler also refreshes this state before its ordinary scheduling pass, so hidden/background rendering is not required for musical correctness. Transient swing and morph positions never author mute state. Ink briefly lifts during the horizontal morph, then returns against the settled layout; opaque black paint cannot hide an audible transitional node. In Black Paint mode, a tap removes the topmost blot using the same logical shapes with a forgiving selection margin. Its translucent residue dissolves over 220 ms. Other overlapping blots and scissors reasons remain intact. Wash was removed. A gesture starting on blank space can still stamp a short painted trail.
4. **Colour.** `src/drawgrid/dg-line-style.js` now owns the original DrawGrid blue/pink/green/yellow palette. Normal drawing, normal random line generation, generated authored strokes and Free Play reuse it. The luminous subdued string, bright playback core and glowing audible nodes remain.
5. **Physical ends.** `looseEndMotion()` combines a damped lateral sine with downward settling and a small vertical overshoot. It settles 32 CSS pixels downward, with local correction so the loose ends hang below the connection. Deformation fades before neighboring nodes. A 350 ms smooth pull-back restores the exact base curve after mend. Presentation timestamps live outside authored/DrawGrid state and use elapsed physical time, so BPM, Pause and Return to Start cannot restart a cut. Reloaded cuts start settled. No rope simulation or geometry accumulation exists.
6. **Shared random rule.** The audit found three normal DrawGrid actions: line regeneration uses 35% rests; its 32-step option repeats an eight-step 25% rest motif with 12% final-bar variation; block randomisation toggles at 50%; note regeneration preserves approximate previous density and guarantees an active column. There was no shared minimum-survival or seeded helper. `selectDrawGridSilence()` extracts the **line** policy, the closest match for Free Play strings. Normal DrawGrid line Randomise and both Free Play tools now call it. It preserves at least one eligible whole column, treats voices in a column together, and ensures a rest when more than one eligible column exists. The other DrawGrid actions retain their existing behavior. `seededRandom()` centralizes the LCG previously used for deterministic splat droplets.
7. **Random Scissors.** A compact dice action beside the selected tool computes canonical target IDs first. Cuts commit immediately. A scissors glyph flies over those same IDs along short arcing paths; each target's local swing starts at its scheduled visit. Flight takes at most 1.1 seconds and follows current displayed node positions if layout changes. `randomCutIds` records ownership so Randomise Again replaces prior random cuts while retaining manual cuts and paint.
8. **Random Paint.** The same selector chooses eligible nodes. Each selected node receives a centered, seeded splat whose size is bounded by nearby nodes. Actual geometric coverage determines all affected IDs, including co-located voices; a candidate that would cover every eligible survivor is rejected. Up to three additional small cosmetic blots are accepted only when the canonical test confirms that they cover no node. These blots cannot change the selected musical coverage. Random Paint does not modify scissors reasons.
9. **Determinism and replacement.** Identical seed and source produce identical selections and shapes. Each new button press intentionally uses a new seed. Random paint is tagged `randomTool: 'paint'`; another press replaces that family and retains manually added paint. Seeds/shapes and canonical flags persist with existing scene/DrawGrid state. Removing one covering splat recomputes the union of all remaining coverage. A newly drawn line also receives coverage from existing ink before playback admission.
10. **Verification.** All 137 targeted tests passed. They cover exact rendered-shape boundaries, droplets, logical canvas sizes, cross-line coverage, overlapping removal, independent reasons, seeded selection, polyphonic column survival, replacement, cosmetic exclusions, swing/overshoot/damping, timed scissors visits, mend/no-drift, persistence, source pitch, folded board editing, visual queues, normal duration and transport. Browser QA used an eight-note line and a capped 32-note/1536-tick phrase, coiled and uncoiled, manual/rapid overlapping paint, tap removal, manual and random cuts, settled mend, both Randomise actions and Again, save/reload, Pause/Resume, BPM 120→170 and Return to Start. Audits found **zero coverage/flag disagreements and zero later audio admissions for covered notes**. Removing the top of two covering splats left one cover and kept the note muted. Mend restored exactly its cut. Tempo preserved paused tick 71213; Start reset both phases to zero without changing cuts. Final reload preserved notes and paint exactly. No browser errors were observed. Mouse interaction was tested; physical touchscreen hardware was not available.

The visible string now shares DrawGrid colours, the separated ends hang clearly downward, and paint obscures the same regions used for silence. Scissors motion is a short presentation over committed target IDs; it never controls transport or changes pitch.
