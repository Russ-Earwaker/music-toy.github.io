# Free Play silence synchronization and bulk resets

1. **Heal all cuts.** Each line's action group exposes **Heal all cuts** while Scissors is selected. It clears that line's `scissorMuted` flags and `randomCutIds`, then uses the existing 350 ms mend animation to pull the ends back onto the stored base curve. Paint is untouched. An in-flight scissors animation stops visiting that line. Notes, IDs, pitches, ticks, geometry, definitions and transport remain intact.
2. **Wipe all paint.** While Black Paint is selected, each line has **Wipe all paint**. It removes the splats owned by that line, including manually placed and random paint, with the existing dissolve effect. Canonical coverage is recomputed from all remaining splats. Scissor flags are untouched. New manual splats belong to the nearest line rather than always the first line, making the local reset meaningful. On an empty page, a toolbar Wipe action removes only decorative page paint.
3. **Canonical state.** Ordinary DrawGrid `authoredNotes` remain authoritative: `{id, col, sourceMidi, scissorMuted, paintCovered}`. Playback uses `!scissorMuted && !paintCovered`. Original path and paint provenance remain on the existing Free Play metadata. No notes are deleted or reconstructed from board appearance.
4. **Shared publication and switch boundary.** The old Free Play setter changed editor notes, called `__seqTouch`, and patched `__sharedToyState` directly. That could leave linked `sharedPattern` stale. It now calls the generic DrawGrid `publishAuthoredChange()`, which emits the normal `drawgrid:update` event and invalidates presentation caches, followed by the existing linked-controller `edit()` path. The established controller captures canonical state and builds `sharedPattern` from that same snapshot. The ad hoc shared-state writes are removed from silence edits. Before Back to Board hides Free Play, coverage is refreshed and all its generated grids synchronously pass through this same publication path. Existing future-audio cancellation, visual-queue cleanup and scheduler-cursor handling are retained; transport is never restarted.
5. **Board presentation.** The ordinary DrawGrid renderer reuses its dim disabled-node appearance for an authored silent cell. Source flags participate in the node cache key, so Heal/Wipe cannot leave a stale dim or bright node. Pitch labels and octave markers remain. If a folded cell contains several voices, it remains active-looking while any voice is audible. No scissors, paint graphics or new rest-editing UI were added to the board.
6. **Round trip and scope.** Board and Free Play share the same authored notes, so returning to Free Play retains the same cuts and splats. Bulk actions are line-specific, not page clears. They retain other lines' cuts and owned paint and never clear unrelated board toys. If a single physical splat also covers another line, removing that splat naturally recomputes its shared coverage; paint owned by other lines remains. Existing global Clear behavior and randomisation rules are unchanged.
7. **Verification.** All **143 targeted tests passed**, including new bulk-reset, source identity, multi-grid round-trip, JSON persistence, dim-cell/multiple-voice and linked-publication regressions, plus the existing silence, geometry, pitch, duration, transport and visual-queue suites. The linked regression checks playback immediately after publication, before waiting for peer hydration. Syntax checks and `git diff --check` passed.

Browser QA used two separate lines while playback continued. The first had active notes at steps 0/2/4/6, a cut at 1, paint at 3, and both reasons at 5. Board audio admitted exactly 0/2/4/6; **zero muted notes were admitted**, including the first playback after reload before reopening Free Play. Editor and shared note arrays agreed. The board visibly dimmed the three silent cells.

Board → Free Play retained all flags and paint exactly. Heal on line 1 cleared its cuts while preserving paint at steps 3/5 and leaving line 2 unchanged. Its transport clock mapping was identical before/after. The healed state survived reload on the board. Wipe on line 1 then restored its remaining notes, retained line 2's cut/paint, and preserved all note IDs, pitches, ticks, paths and definition IDs. That wiped state also survived board reload. Wipe on line 2 removed its paint but kept its cut at tick 48 silent; Heal then restored that final cut. No browser errors were observed. Mouse input was verified; physical touchscreen hardware was not tested.
