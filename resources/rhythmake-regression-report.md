Rhythmake regression pass

1. The four-part melody disappeared because Auto-Arrange only invoked its phrase builder when no melody source existed. An authored melody therefore bypassed generation and became a single repeated DrawGrid.

2. Auto-Arrange now uses the phrase builder for an authored melody too. The authored DrawGrid remains chunk 1 without changing its notes, instrument, role, volume or mute. The existing generator supplies three separate editable continuation chunks. An internal shared Sequence owns their order; A and B each contain four real linked editors, presented horizontally. Arrange Again reuses this definition. Browser checks confirmed chunk 3 edit propagation, independent positions/connections, regeneration and reload.

3. New occurrence scheduler state began at the polling tick, losing cycle-boundary notes whenever the poll arrived slightly late. It now admits boundary notes through the existing bounded late-grace window. Bouncer snapshot/quantization callbacks also referenced an undefined recorder, and early snapshot application ran before recorder initialization. Full Bouncer Linked Copies were additionally excluded by a legacy lightweight-instance initializer guard. These paths are repaired; root cycles retain the existing Heartbeat phase origin and natural tick duration.

4. Bouncer replay effects were queued on the callback's editor and drained by its renderer only if their playback-instance ID matched the currently displayed instance. This could drop or misdirect events across occurrences and Linked Copies. Successful audio admission now queues an occurrence-owned event for the visible playback toy. The board services it against the owning transport tick and activates its block/edge feedback independently of render visibility and physics collisions.

5. Rippler kept one `_visFlashAt` value per block, so lookahead could overwrite an earlier flash with a later one. Ring spawning also depended on render/bar callbacks and spawn guards. Every admitted replay note now initiates one note-feedback event and one ring on its owning view, without debounce. Learning-pass collision notes use the same admission callback. Replay-only rings cannot discover new musical collisions, and legacy replay bar callbacks no longer independently create them. Each ring keeps its logical origin and transport-tick radius.

6. Frame-time animation remains for particle motion, cosmetic glow/flash decay and learning-pass physics between collisions. Bouncer replay position and Rippler replay-ring radius derive from transport state. Audio admission supplies replay event creation and identity. Pause/tempo/seek changes deliver already-sounding queued events before cancelling future events; seek clears stale deterministic visual state without editing patterns.

7. Browser proof and scene are saved in `debug-output/regression-qa/report.json` and `scene.json`. The full run reached tick 20,941: 54.53 natural cycles and over three complete arrangements, with repeated zoom/resize/DPR changes, pause/resume, tempo changes and both reset states. Counts for **each** original and Linked Copy: Bouncer 108 scheduled / 108 audio / 108 visual; Rippler 108 scheduled / 108 audio / 108 visual / 108 rings. No JavaScript exceptions occurred. The final quick check also confirmed both paused Bouncer positions return to their authored trajectory origin and both Ripplers have zero stale rings. Unit coverage independently runs 100 late-polled root cycles per toy, verifying 200 exact tick events and 200 visual events each. Audio counts measure admitted scheduled voices whose onset has passed; subjective listening remains manual.

8. The four Beat Swarm failures were genuinely pre-existing Windows newline failures. The unchanged HEAD source reproduces all failed extraction matches when converted to CRLF; all matches succeed after LF normalization. `debug-output/regression-qa/beat-swarm-baseline.json` records that comparison. The two test files now normalize input newlines while retaining their assertions. No Beat Swarm production source changed. The full suite passes all 956 tests.
