Reusable Sequence Structure Instances are implemented. A Sequence Master’s Advanced menu offers **Create Linked Copy** and an optional name. Linked copies have stable names such as `Sequence 1.1` or `Melody Phrase.3`, an INSTANCE marker, their own board position/connections, and four ordinary visible child Toy Instances in the four-part example. The existing board placement and relationship flash/tether treatment are reused; there is no sub-board.

The Master’s actual connections remain authoritative for child membership and order. Copies materialise only linked toy references and their board connections. They read live source data through the existing Toy Instance path; note data is never copied into them. Master additions/removals/reordering reconcile all copies, retaining unaffected child identities. Each expanded copy compiles through the existing production scheduler as an independent occurrence, inheriting its surrounding chord context and the normal Heartbeat phase. No harmony algorithm or new runtime playback system was introduced.

This first pass supports **Sequence Masters with direct toy children**. Nested structures and implicit chains are deliberately excluded with a clear creation/connection error. Copy-owned children cannot be rewired or deleted independently through the UI; membership is edited on the Master. Master type conversion is blocked while linked copies exist. Deleting a Structure Instance removes its owned child Instances/cables, preserving the Master, sibling copies and all source toys. Master deletion is blocked until its copies are removed. New Creation releases these dependencies first; a single confirmed New Creation cleared all 22 toy objects, 15 structures and 33 connections in the browser proof.

New Auto-Arrange melody fills now use **four ordinary, visible, editable eight-step DrawGrid Masters and one Melody Phrase Sequence Master**. The existing normal four-bar melody generator supplies the phrase; its output is split into four one-bar states, including strokes and note/rest masks. No additional phrase note data is retained elsewhere. A and B have separate linked Phrase Instances, with four linked child Toy Instances each. Short rhythm/accompaniment parts use ordinary Repeat structures to maintain full section density. Intro/A/B/Outro remain four bars each, with 1/3/4/1 layers; B retains F/G/Am/C and its extra percussion, with no octave transpose.

Arrange Again reuses the Phrase Master, all edited chunk Masters and the edited extra percussion source within the same board/Heartbeat scope. It replaces owned arrangement structures, Phrase Instances and generated child Instances without accumulating sources. Existing authored or previously generated standalone melody toys, including 32-step toys, are retained and continue to use the existing ordinary toy path. Failure rollback preserves the previous linked expansion identities, connections and source edits; a deliberately failed B-copy creation is covered by a regression test.

Persistence stores `masterStructureId`, monotonic structure-copy numbering, child ownership/slot links, positions and normal connections. Toy Instances still save empty authored state. Reload retains copy/child IDs, membership, ordering, source notes, volume and mute. Child audio continues to route through its Master’s actual bus.
